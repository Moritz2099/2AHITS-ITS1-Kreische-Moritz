# wc (word count)
mit wc kann man die wörter einer Datei zählen.
BSP
wc datei.txt

Ausgabe:

10  50  300 datei.txt

Bedeutung:

10 Zeilen
50 Wörter
300 Bytes

# cut
Mit cut kann man einzelne Spalten ausgeben.
```sh

cut -c 1-5 datei.txt

Gibt Zeichen 1 bis 5 jeder Zeile aus.

Mit Trennzeichen arbeiten

Beispiel-Datei:

max,25,deutschland
anna,30,österreich
```

# sed — Text bearbeiten

sed ist ein Stream-Editor zum Ersetzen, Löschen oder Verändern von Text.

Text ersetzen
```sh
sed 's/apfel/orange/' datei.txt
```

Ersetzt das erste Vorkommen pro Zeile.

Alle Vorkommen ersetzen:
```sh
sed 's/apfel/orange/g' datei.txt  // ersetzt das wort apfel mit orange
```

```sh
-m
-l
-L
-w
```
Finde heraus (Recherchieren, Experimentieren) was die folgende Kommandozeile macht (lies die man page von wc ab “Description”):

```sh
$ echo eins zwei drei | wc - klassenkassa.csv
```
Lösung:

-m: Zählt die Anzahl der Zeichen.

-l → Zeilen zählen

-L → Länge der längsten Zeile

-w: Wörter zählen

```sh
$ echo eins zwei drei | wc - klassenkassa.csv
```

gibt den Text „eins zwei drei“ aus, leitet ihn an wc weiter und zählt anschließend die Anzahl der Wörter.
