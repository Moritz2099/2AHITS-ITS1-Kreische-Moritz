   # Übung 3.2(SHA256-shell)

   
   Kali terminal öffnen und  mit folgenden Befehl die Datei herunterladen
   ```sh
    curl -O https://www.franzmatejka.at/htl/doc/ITSI_2/05_hashing_encoding/data/goethe.txt
   ```
 	 danach mit ```sh
   openssl dgst -List```
    Alle Hash verfahren anzeigen lassen

   wir verwenden dann den Befehl```-SHA-256```
   dann alles zusammen
   ```sh
   openssl dgst -sha256 goethe.txt
    ```

   ```sh
   SHA2-256(goethe.txt)= a911a35ff92bcd4250c063a0547dae3f1ba2b839eaf12b64c955cf3ff7e570e0
   ```
